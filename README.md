## 📌 Sobre
 
Este repositório reúne meus estudos, exercícios e projetos práticos da disciplina de **Programação Orientada a Objetos**, cursada em Java durante a graduação em Engenharia de Software. A ideia é documentar minha evolução ao longo do semestre — desde os conceitos fundamentais até implementações mais completas — servindo tanto como material de revisão pessoal quanto como registro público do meu aprendizado.
 
## 🎯 Objetivos
 
- Consolidar os pilares da orientação a objetos: **classes, objetos, encapsulamento, herança, polimorfismo e abstração**
- Praticar a resolução de problemas aplicando POO de forma idiomática em Java
- Construir um histórico de commits que reflita evolução real de entendimento, não só entrega de exercícios
- Ter uma base sólida de Java para conectar futuramente com outras áreas de interesse, como back-end e IA aplicada

## 🛠️ Tecnologias
 
- **Java**
- **Git & GitHub** para versionamento e histórico de aprendizado
